The site uses a shared, AMOLED-friendly dark theme with a glassmorphism interface:

* CSS-only animated aurora background
* Frosted glass panels with soft borders
* Floating navigation and settings controls
* Smooth scrolling and improved scrollbar styling
* Focus styles and reduced-motion support
* Animated page entrance effects
